# UI SDK

Before using UI SDK, follow the `ui-sdk` skill if installed and read
`node_modules/@ui-sdk/svelte/docs/llms.txt` from the workspace that uses it
(currently `packages/ui`). When building a new component, also search
`node_modules/@ui-sdk/svelte/docs/core.md` by heading and read `rendering.md`
in the same directory.
