## Annotations API

Use the Annotations API to retrieve [Georeference Annotations](/georeference-annotations) for maps, IIIF images, canvases, manifests, organizations, and lists. These annotations describe how maps are georeferenced and can be used in Allmaps Viewer, mapping libraries, and other tools that support the format.

[View API documentation](/api/annotations)

## REST API

Use the REST API to query maps, manage organizations and import and update IIIF resources. This API requires authentication for most endpoints.

[View API documentation](/api/rest)
