Use [Allmaps Editor](https://editor.allmaps.org/) to georeference historical maps
in your browser. This guide takes you through opening a map, drawing a mask,
adding control points, and viewing the result.

To get started, you’ll need the URL of a IIIF resource containing a map. See
[Find maps to georeference](/guides/find-maps-to-georeference) for collection
links and help finding a IIIF URL.

### What is georeferencing?

Georeferencing connects places on a historical map to their geographic
locations. You identify matching points on the map image and a modern reference
map—for example, a church, a road junction, or a bridge. Each pair is called a
**ground control point (GCP)**.

Allmaps uses these control points to calculate a transformation that positions
and warps the image so it can be displayed over a modern basemap.

The original image stays on the institution’s IIIF server. Allmaps stores your
control points, map mask, and transformation settings in a
[Georeference Annotation](/georeference-annotations). This allows Allmaps to
display the georeferenced map in your browser without creating a separate image
file.

### Step 1: Open a IIIF resource

1. Open [Allmaps Editor](https://editor.allmaps.org/).
2. Paste a IIIF resource URL into the input field and press <kbd>Enter</kbd>. You can
   also choose one of the example maps on the Allmaps Editor homepage.
3. In the **Images** tab, select the image you want to georeference. A resource
   may contain a single image or several images, such as the pages of an atlas.

The navigation at the top takes you through four steps: **Images**, **Draw
mask**, **Georeference**, and **Results**. You can move between them as you work.

If the image already has a mask or control points, someone has started
georeferencing it. You can review and improve their work.

:::note[Supported resources]
Allmaps Editor supports:

- **IIIF Manifests** containing one or more images.
- **IIIF Collections** containing Manifests or other Collections.
- **IIIF Image Services** for individual images.
- **Georeference Annotation URLs** from the Allmaps Annotations API.

See the [IIIF guide](/iiif) for an introduction to these resources.
:::

:::note[If a resource won’t open]
First, check that you copied a IIIF resource URL rather than the address of a
collection’s web page.

A resource may fail to load if its server is unavailable, its IIIF data is
invalid or unsupported, or its server prevents other websites from accessing
it through cross-origin restrictions (CORS).

If you need help, [report an issue](https://github.com/allmaps/allmaps/issues)
and include the resource URL and the error message.
:::

### Step 2: Draw a mask

A **map mask** outlines the part of the image you want to georeference. It
determines which area is displayed in the results and in Allmaps Viewer.

1. Open the **Draw mask** tab.
2. Zoom in and click around the edge of the map to draw its outline.
3. Click **Finish** or the starting point to close the mask. To cancel an
   unfinished mask, click **Cancel**.

You can adjust the mask after drawing it.

:::note[What should the mask include?]
Include the map area you want to display, usually leaving out borders, legends,
and decorative elements. The outline depends on the map and how you want to
use it.

If an image contains several maps, such as a main map and smaller inset maps,
you can draw a separate mask for each. Each map can then have its own control
points.
:::

#### Edit a mask

You can refine the outline in the **Draw mask** tab:

- Drag a point to move it.
- Click and drag an edge to add a point.
- Right-click a point to remove it.

If the image contains several maps, open the **Maps** panel and select the map
you want to edit. Its mask is highlighted with a thicker outline.

To delete a map, click its trash icon in the **Maps** panel and confirm. This
removes the map, including its mask and control points.

:::caution[Your data in Allmaps]
Allmaps Editor saves your edits automatically. Your masks, control points, and
transformation settings are published as open data under
[CC0](https://creativecommons.org/public-domain/cc0/). They are also published
daily as an open dataset on the
<a href={new URL('/data', homepageBaseUrl).href}>Allmaps homepage’s data page</a>.

Georeferencing is shared: anyone opening the same map can see and edit this
data. Changes you make also affect what other people see.

To keep a copy of your work at a particular moment, save its Georeference
Annotation. See [Share and export your map](#share-and-export-your-map)
for details.
:::

### Step 3: Add ground control points

Ground control points (GCPs) connect locations on the historical map to the same
places on a modern reference map.

1. Open the **Georeference** tab. The map image appears on the left and the
   reference map on the right.
2. Find the area shown on the historical map. You can zoom and pan the reference
   map or use the search button to find a place.
3. Choose a recognizable feature, such as a church, road junction, or bridge.
   Click its location on both sides to create a ground control point. Matching
   numbers identify the pair.
4. Add at least three ground control points. Ideally, they are spread out over
   the map and do not lie on a straight line.

Choose features whose locations have stayed the same over time. Adding more
well-placed ground control points can help improve the alignment.

Allmaps uses a **polynomial transformation** by default, which requires at least
three ground control points and works well for most maps. You usually don’t
need to change it.

After adding three ground control points, the transformed mask appears on the
reference map. Open the **Results** tab to see the historical map overlaid on
the reference map.

:::note[navPlace]
If the loaded IIIF Manifest contains a [navPlace](https://iiif.io/api/extension/navplace/) property, this will be used to initiate the map view.
:::

#### Edit ground control points

In the **Georeference** tab, drag a ground control point on either the image or
the reference map to adjust its position.

Open the **Maps** panel to see the ground control points for the selected map.
Select a ground control point in the list to locate it in both views. To remove
it, click its trash icon and confirm.

If the image contains several maps, select the map you want to work on in the
**Maps** panel. Each map has its own ground control points.

#### Navigate the image and reference map

Zoom and pan either view to position your ground control points precisely. Use
the search button to find a place on the reference map.

To rotate the image or reference map, hold <kbd>Ctrl</kbd> and drag with the
left mouse button.

#### Adjust the display

Click the cogwheel icon in the map view to open the display settings.

The **Georeference** and **Results** tabs have separate settings for map opacity
and mask visibility. By default, the **Georeference** tab shows the transformed
mask. Increase its opacity setting to also display the warped map image while
placing ground control points.

You can also choose a different background map, enter a custom XYZ tile URL,
or load a Georeference Annotation to use another georeferenced map as a
reference.

#### Import existing georeferencing data

If you already have a mask or ground control points for an image, you can import
them into Allmaps Editor instead of drawing them again.

1. Open the image and select the map you want to update. If it doesn't have a
   mask yet, draw a temporary mask with at least three points.
2. Open the **Maps** panel.
3. Choose **Edit or import mask…** or **Edit or import GCPs…** for the selected
   map.
4. Paste your data into the text field, or use **Upload** to read it from a file.
   The dialog lists the supported formats and checks your data.
5. Click **Save**, then check the imported mask or ground control points on the
   map.

Masks can be imported as a list of image pixel coordinates, a JSON array, or an
SVG polygon. Ground control points can be imported from formats used by QGIS,
GDAL, and ESRI. Image coordinates must correspond to the original IIIF image's
dimensions.

### Step 4: View and export results

Open the **Results** tab to see your georeferenced map overlaid on the reference
map. The image is cropped to the mask you drew.

Zoom and pan to check how well recognizable features line up. Hold
<kbd>Space</kbd> to temporarily hide the historical map and see the reference
map underneath. Release it to show the historical map again.

If the alignment needs improvement, return to the **Georeference** tab to
adjust or add ground control points.

Use the **Show** menu at the bottom to choose which maps to display:

- **Current map:** the selected map.
- **Current image:** all maps in the selected image.
- **All images:** all maps across the loaded resource.

The available options depend on the resource you opened.

#### Choose a transformation

A transformation determines how Allmaps positions and warps the historical map
using your ground control points. The default, **Polynomial**, works well for
most maps. You usually don’t need to change it.

To try another transformation, open the **Maps** panel, select a map, and use
the **Transformation** menu:

- **Polynomial** moves, rotates, scales, and skews the image to fit the ground
  control points.
- **Helmert** moves, rotates, and scales the image uniformly, preserving its
  shapes and proportions.
- **Thin plate spline** bends the image to pass through each ground control
  point. It can accommodate local differences, but may introduce distortion
  between points.

Polynomial and Helmert find an overall fit, so individual ground control points
may not align exactly. Before changing the transformation, check that your
ground control points are accurate and spread across the map.

#### Share and export your map

Click **Export** to open the export panel. Under **Export options for**, choose
**Current map**, **Current image**, or **All images**. The available options
depend on the resource you opened.

The panel provides links you can open or copy:

- **View in Allmaps Viewer:** explore and share the selected maps. Choose
  **Latest version** to include future edits, or **Current version** to keep
  the link fixed to the current georeferencing. See
  [Share a map](/guides/viewing-maps#share-a-map) for details.
- **Georeference Annotation:** access the georeferencing data for your selection.
  Multiple maps are returned together in an Annotation Page. Use **Code** to
  inspect the annotation.
- **XYZ map tiles:** use the georeferenced maps as a tile layer in GIS software
  or a web map.

Select **Show more export options** for GeoJSON, web mapping code examples, and
instructions for creating a GeoTIFF.

See [Georeference Annotations](/georeference-annotations) for details about the
data format, or [Using maps in other tools](/guides/using-maps)
for more ways to use your work.

### Versions and shared edits

Anyone can edit a map in Allmaps Editor, including maps you have georeferenced.
Allmaps keeps a history of the georeferencing data, so you can refer to a
specific version even after further edits.

An annotation URL without a version returns the latest georeferencing data.
A versioned URL adds `@` followed by a version identifier:

<div class="api-examples">

| Version | Annotation URL |
| --- | --- |
| Latest | <a href="https://annotations.allmaps.org/maps/1bfb1eb4198e7240">{"https://annotations.allmaps.org"}<wbr />{"/maps"}<wbr />{"/1bfb1eb4198e7240"}</a> |
| Specific version | <a href="https://annotations.allmaps.org/maps/1bfb1eb4198e7240@c83337fa4b8051c9">{"https://annotations.allmaps.org"}<wbr />{"/maps"}<wbr />{"/1bfb1eb4198e7240"}<wbr />{"@c83337fa4b8051c9"}</a> |

</div>

Each annotation includes its versioned URL in `body._allmaps.version`. Copy
this URL when you want to share or use a particular version. You can also open
it in [Allmaps Viewer](https://viewer.allmaps.org/).

Use the unversioned URL to follow ongoing improvements, or the versioned URL
to keep the georeferencing fixed for a publication or project.

:::note[Planned improvements]
We’re planning a more advanced version management system for maps. Users will
be able to log in, keep track of their contributions, and retain access to
their own work even as others continue editing the same maps.
:::
