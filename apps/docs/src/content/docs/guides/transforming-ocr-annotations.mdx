Turn text labels and traced features on a historical map into GeoJSON you can
display on a modern map or analyze in a GIS. Allmaps uses the image's
[Georeference Annotation](/georeference-annotations) to transform their shapes
from pixels to longitude and latitude. Your code keeps the text and other
metadata as properties of the resulting features.

This guide follows two examples: words detected by optical character
recognition (OCR) around a San Francisco brewery, and buildings traced
with [Annotorious](#from-annotorious-to-geojson) on a factory map in
Massachusetts. Both use the same workflow: transform the geometry and retain
the annotation's contents.

## Inside an OCR annotation

Each detected word is stored as a W3C Web Annotation. Its `body` contains the
recognized text, while its `target` identifies the IIIF source image and an
SVG polygon in full-resolution image pixels. Here is the complete annotation
for **FERMENTING**:

A separate [Georeference Annotation](/georeference-annotations) supplies the
control points and transformation for the same image. Together, these two
annotations let you transform the word's polygon to geographic coordinates
and retain its text as a GeoJSON property.

## Transform the polygons

The following JavaScript loads both inputs, creates one transformer for the
map, and applies the [SVG conversion](/guides/svg-to-geojson) to each OCR
selector. Each annotation in this example contains one polygon, which becomes
one GeoJSON feature with the text and source image ID in its properties.

```js
import { parseAnnotation } from '@allmaps/annotation'
import { GcpTransformer } from '@allmaps/transform'

const annotation = await fetch(
  'https://annotations.allmaps.org/maps/ad38324ab9d18a27@7eef0e705892f244'
).then((response) => response.json())
const labels = await fetch(
  'https://docs.allmaps.org/examples/ocr/san-francisco.ocr.json'
).then((response) => response.json())

const [georeferencedMap] = parseAnnotation(annotation)
const transformer = GcpTransformer.fromGeoreferencedMap(georeferencedMap)

const features = labels.map(({ body, target }) => {
  const [feature] = GcpTransformer.transformSvgStringToGeojsonFeatureCollection(
    transformer,
    target.selector.value
  ).features

  feature.properties = { text: body.value, imageId: target.source.id }
  return feature
})

const geojson = { type: 'FeatureCollection', features }

console.log(JSON.stringify(geojson, null, 2))
```

## From Annotorious to GeoJSON

The same conversion works for manually drawn features. This example uses
three buildings traced with [Annotorious](https://annotorious.dev/) on a map
of the [Glendale Elastic Fabrics Company](https://www.digitalcommonwealth.org/search/commonwealth:2r36vc45n)
in Easthampton, Massachusetts, from the American Textile History Museum
collection on Digital Commonwealth. Here the polygons outline **buildings**,
rather than printed text:

The example uses a [versioned Georeference Annotation](https://annotations.allmaps.org/maps/654b26fa1850e5fc@26f09f0bcf3066b5)
with 22 control points and a thin-plate-spline transformation to align the mill
buildings. Pinning the annotation version keeps the displayed outlines and
downloadable GeoJSON consistent if the map is edited later.

Each building annotation stores its outline as an SVG polygon in
`target.selector.value`. Its `body` is an array of text entries, and its `id`
identifies the drawing. A separate Georeference Annotation supplies the
image's control points and transformation. The code below transforms each
outline and retains the drawing's text and annotation ID as GeoJSON properties.

Adapt the conversion as follows:

```js
import { parseAnnotation } from '@allmaps/annotation'
import { GcpTransformer } from '@allmaps/transform'

const annotation = await fetch(
  'https://annotations.allmaps.org/maps/654b26fa1850e5fc@26f09f0bcf3066b5'
).then((response) => response.json())
const drawings = await fetch(
  'https://docs.allmaps.org/examples/annotorious/buildings.annotations.json'
).then((response) => response.json())

const [georeferencedMap] = parseAnnotation(annotation)
const transformer = GcpTransformer.fromGeoreferencedMap(georeferencedMap)

const features = drawings.map((drawing) => {
  const [feature] = GcpTransformer.transformSvgStringToGeojsonFeatureCollection(
    transformer,
    drawing.target.selector.value
  ).features

  feature.properties = {
    annotationId: drawing.id,
    text: drawing.body.map((body) => body.value).join('\n')
  }
  return feature
})

const geojson = { type: 'FeatureCollection', features }

console.log(JSON.stringify(geojson, null, 2))
```
