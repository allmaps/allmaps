[Allmaps Viewer](https://viewer.allmaps.org/) is a web application for viewing Georeference Annotations.

\[Work in progress]

- Go back and forth between the original image and warped map by clicking the Map and Image buttons in the bottom left corner.
- If the IIIF manifest contains multiple images and if more than one were georeferenced (and exported), all images are rendered at once.

Tricks:
  - Hold and release the spacebar to quickly hide/show the map
  - Press B or use the right knob to remove the background color
  - In case of multiple maps use \[ and \] or the arrows in the bottom left to browse the collection (the selected map is moved to the top)
  - Right click on a map to change the layer order
