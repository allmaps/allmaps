## Introduction

Allmaps helps you georeference, explore, and use digitized historical maps. Its
web applications, APIs, and open source libraries connect maps from libraries,
archives, and museums to modern mapping tools.

The map images remain with the institutions that publish them and are accessed
through [IIIF](/iiif). Allmaps does not store digitized map images or derived
images like GeoTIFFs or map tiles. It stores georeferencing data separately as
[Georeference Annotations](/georeference-annotations). These small JSON documents
describe how a map's image coordinates relate to geographic coordinates, so the
map can be placed on a modern map.

You can use Allmaps in your browser, integrate georeferenced maps into your own
website, or build applications with its TypeScript libraries. Allmaps is built
around open source software, open standards, and open data, making it easier to
share your work and use it with other tools.
