<div slot="props">

| Prop               | Values                                                                      | Default        |
| ------------------ | --------------------------------------------------------------------------- | -------------- |
| `variant`          | `default`, `primary`, `destructive`                                         | `default`      |
| `shape`            | `rounded`, `pill`                                                           | `rounded`      |
| `icon`             | Optional Svelte snippet for the icon                                        | unset          |
| `iconPosition`     | `leading` or `trailing`                                                     | `leading`      |
| `iconOnly`         | Square control; supply an accessible label                                  | `false`        |
| `active`           | Visual selection; supply the appropriate ARIA state separately              | `false`        |
| `disabled`         | Disable activation; links lose their href and leave the tab order           | `false`        |
| `loading`          | Replace the icon with a spinner, disable activation, and expose `aria-busy` | `false`        |
| `loadingIndicator` | Optional Svelte snippet for the loading indicator                           | `LoadingSmall` |
| `href`             | Render a native anchor instead of a button                                  | unset          |
| `ref`              | Bindable native button or anchor element                                    | `null`         |
| `children`         | Button label                                                                | unset          |

</div>
