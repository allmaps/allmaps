<div slot="usage">

Give the dialog an accessible name with `Dialog.Title`. Use `Dialog.Trigger` to open it and return focus to the opener on dismissal, or bind `open` on `Dialog.Root` to control it from your app.

```svelte
<script lang="ts">
  import * as Dialog from '@allmaps/ui/dialog'
  import { Button } from '@allmaps/ui/button'
</script>

<Dialog.Root>
  <Dialog.Trigger>
    {#snippet child({ props })}
      <Button {...props}>About this atlas</Button>
    {/snippet}
  </Dialog.Trigger>
  <Dialog.Content>
    <Dialog.Header>
      <Dialog.Title>About this atlas</Dialog.Title>
      <Dialog.Description>This atlas contains 48 map sheets.</Dialog.Description
      >
    </Dialog.Header>
  </Dialog.Content>
</Dialog.Root>
```
