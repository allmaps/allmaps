<div slot="usage">

Give the dialog an accessible name with `Dialog.Title`. Use `Dialog.Trigger` to open it and return focus to the opener on dismissal, or bind `open` on `Dialog.Root` to control it from your app.

The default backdrop uses 50% black. Set `backdrop="dark"` on `Dialog.Content` for 90% black, as in the Allmaps Viewer About dialog. The backdrop and panel fade in and out, and respect the user's reduced-motion preference.

Use the `background` snippet on `Dialog.Content` for decorative content between the backdrop tint and the panel. The decoration starts fading in once the panel is fully visible. It appears immediately with reduced motion and stays out of keyboard and pointer interaction. Viewer uses the reusable `MovingMapsBackground` component from `@allmaps/ui` in this snippet.

```svelte
<Dialog.Content backdrop="dark">
  {#snippet background()}
    <MovingMapsBackground {mapsApiBaseUrl} />
  {/snippet}
  <Dialog.Title>About Allmaps Viewer</Dialog.Title>
</Dialog.Content>
```

For long content, put the title in the `stickyHeader` snippet on `Dialog.Content`. The title and built-in Close button stay visible while the body scrolls. Set `showCloseButton={false}` if you provide your own dismissal control.
