<div slot="usage">

Set `align` on `DropdownMenu.Content` to `start`, `center`, or `end` to align the menu with its trigger. Use the arrow keys to move between enabled items and Escape to return to the trigger. With **Enable F shortcut** checked, press **F** on the trigger or inside the menu to toggle the map’s favorite status.

Hover over **Add to collection** or focus it and press **Right Arrow** to open its submenu. Choose a collection with Enter, or press **Left Arrow** to return to the parent item. Wrap `SubTrigger` and `SubContent` in `DropdownMenu.Sub` to create a submenu.

Place an icon inside an item and use `DropdownMenu.Shortcut` to display its keyboard shortcut. The app handles the keypress. For a navigation item, render a link in the `child` snippet and spread the supplied props onto it.
