<div slot="usage">

Allmaps uses the [shadcn-svelte Kbd component](https://www.shadcn-svelte.com/docs/components/kbd). To display a shortcut like Shift + Enter, wrap the two keycaps in `Kbd.Group`.

```svelte
<script lang="ts">
  import * as Kbd from '@allmaps/ui/kbd'
</script>

<Kbd.Group>
  <Kbd.Root>Shift</Kbd.Root>
  <Kbd.Root>Enter</Kbd.Root>
</Kbd.Group>
```

The existing `import { Kbd } from '@allmaps/ui'` also renders a single key.
