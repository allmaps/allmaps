<div slot="usage">

LoginDialog uses the shared [Dialog](/components/dialog) with the [AllmapsLogo](/components/allmaps-logo) in its title. Choosing a provider in the playground signs you in locally for the demo.

```svelte
<script lang="ts">
  import { LoginDialog } from '@allmaps/ui/auth'
  import { Button } from '@allmaps/ui/button'

  let open = $state(false)
</script>

<Button onclick={() => (open = true)}>Log in</Button>
<LoginDialog bind:open />
```

</div>

<div slot="props">

| Prop              | Behavior                                                                                                                      |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `open`            | Bind the dialog’s open state. Escape, the close button, and a click outside dismiss it.                                       |
| `apiBaseUrl`      | Allmaps API root used to discover enabled providers when the dialog opens. Defaults to `https://api.allmaps.org`.             |
| `signInProviders` | Optional preloaded list of provider links. Omit to discover all enabled providers and return to the current page after login. |
| `signInURL`       | Optional direct login URL. Used when no explicit provider links are supplied, and skips discovery.                            |
| `returnFocus`     | Optional element to focus when the dialog closes. Use this when the opener is inside a dropdown that closes.                  |

</div>
