<div slot="usage">

For guests, the **Log in** button opens [LoginDialog](/components/login-dialog) directly. For signed-in users, the avatar opens the account menu.

**My session** shows the profile photo from your current Allmaps session for this environment. Choose **Logged in** or **Logged out** to explore each state.

<UsageCode code={`<script lang="ts">
  import { LoginMenu, type LoginUser } from '@allmaps/ui/auth'

let {
user,
signOut
}: {
user: LoginUser | null
signOut: () => Promise<void>
} = $props()

</script>

<LoginMenu {user} onSignOut={signOut} />`} />

To combine account actions with app commands, use `LoginMenuTrigger` inside a [DropdownMenu](/components/dropdown-menu) root and render `LoginMenuItems` inside its content. Pass your app’s dropdown items as children of `LoginMenuItems` to place them between the avatar-and-name header and **Log out**. Both are exported from `@allmaps/ui/auth` and accept the same `user`. Give the trigger an accessible name such as `aria-label="Open Viewer menu"`.

Pass `onLogIn` to `LoginMenuItems` to show **Log in…** for guests. Have it open a `LoginDialog` rendered outside the dropdown. Bind the trigger’s `ref` and pass it to the dialog as `returnFocus`. Signed-in users see their account links and the **Log out** action supplied by `onSignOut`.

</div>

<div slot="props">

| Prop              | Behavior                                                                                                                                                         |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `class`           | Applies classes to the trigger in both session states. Use `size-full` to fill a sized parent.                                                                   |
| `user`            | Pass the app’s session user to show their photo or the guest account icon and the Log out action. Pass `null` for a guest.                                       |
| `apiBaseUrl`      | Allmaps API root used to discover enabled providers when the dialog opens. Defaults to `https://api.allmaps.org`.                                                |
| `signInProviders` | Optional preloaded list of provider links. Omit to discover all enabled providers and return to the current page after login.                                    |
| `signInURL`       | Optional direct login URL. Used when no explicit provider links are supplied, and skips discovery.                                                               |
| `onSignOut`       | App callback that ends the session and updates the user. Return a promise to keep the menu open while signing out. Reject it to show an error and allow a retry. |
| `accountLinks`    | Optional array of `{ label, href }` links to show above Log out.                                                                                                 |

</div>
