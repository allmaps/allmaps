<UsageCode live code={formatUsage({ star: true })} />

The icon fills when starred. Activating the star plays a short pop when motion is enabled. The app owns the starred state and its persistence.

</div>

<div slot="props">

| Prop              | Behavior                                                                          |
| ----------------- | --------------------------------------------------------------------------------- |
| `starred`         | Bind the starred state. Defaults to `false`.                                      |
| `onStarredChange` | Receives the new boolean value on activation.                                     |
| `aria-label`      | Defaults to `Star map`. Include the map title when several stars appear together. |
| `disabled`        | Disable activation.                                                               |
| `ref`             | Bind the underlying button element.                                               |

</div>
